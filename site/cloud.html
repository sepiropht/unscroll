What you get

The same sync, hosted for you.

End-to-end encrypted

Each device encrypts with a key that never leaves your devices. The server stores opaque ciphertext only.

A server you don’t run

The default server in the apps is already Unscroll Cloud. Pair a device with a QR code, as with a self-hosted server.

14-day trial, no card

The trial starts the first time a device syncs. You can subscribe later, or switch to self-hosting at any time.

The apps stay free

One edition, no feature gating. Limits, focus, sleep, and stats do not depend on a subscription.

Privacy

Encrypted data, an anonymous id.

Ciphertext only

The hosted server never sees your encryption key, your passphrase, or your usage in the clear.

What Stripe sees

Only an anonymous account id, plus what you type in Checkout. Usage data is never sent to Stripe.

When access ends

The encrypted server copy is kept for 30 days, then deleted. Data on your devices is never touched, and you can still export it.

No email account

Turning sync on creates an anonymous account. No email, no password.

How to start

The trial lives in the app.

There is no checkout on this site. You start from Settings → Sync → Unscroll Cloud.

  1. 1

    Get the Android app, the desktop app, or the browser extension from the public repository.

  2. 2

    Open Settings, then Sync, and turn sync on.

  3. 3

    Choose Unscroll Cloud — it is the default server URL.

  4. 4

    The 14-day trial starts on the first sync. No card is required. Subscribe later with Settings → Sync → Unscroll Cloud → Subscribe.

Questions

About Unscroll Cloud.

Do I need Cloud to use Unscroll?

No. Every feature works on the device for free. Sync is optional, and self-hosting the sync server is free.

Do I need a card for the trial?

No. The trial starts the first time a device syncs, with no card.

What happens when the trial ends?

You can subscribe or self-host. Your data stays on your devices and can still be exported. The encrypted server copy is kept for 30 days, then deleted.

What does Stripe see?

Only an anonymous account id and what you type in Checkout. Usage data never goes to Stripe, and end-to-end encryption is unchanged.

Can I switch to self-hosting?

Yes. Run your own server and point Sync at your origin. The apps and the encryption stay the same.

Is Cloud a different edition?

No. There is one edition, AGPL-3.0, with every feature included. Cloud only hosts the sync server.
