# Unscroll — Play Store listing (English)

Open-source, local-first screen time. Limits, focus and optional encrypted sync.

- **Full description** (≤4000, 2490 chars):

Unscroll is a free, open-source, local-first screen-time app. It measures how you use your phone, helps you set limits, and can run a focus session when you want a quieter stretch of time. There is one edition. Every feature is included. The source is published under the AGPL-3.0 license at https://github.com/sepiropht/unscroll

WHAT STAYS ON THE DEVICE
Measurements, limits, websites, reminders, and settings stay in the phone's storage. There is no account to create, no advertising, and no audience or crash reporting. Nothing is sent anywhere unless you turn on optional sync.

WHAT YOU CAN DO
• See time spent in each app, by day, week, or month
• Set a daily limit or a schedule for an app or a website
• Start a focus session, with a notification and a home-screen tile
• Get a reminder when you have been on the same app for a while, or when it is time for an eye break
• Pin a widget with today's time
• Export and import your own backup as a JSON file

PERMISSIONS, ASKED ONLY WHEN NEEDED
• Usage access counts screen time per app
• The accessibility service, if you enable it, recognizes the app in the foreground so a limit can be applied, and reads the address bar of common browsers to estimate time per site. It does not read your messages, passwords, or what you type. A full explanation and your consent are shown in the app before Android settings are opened
• Display over other apps shows the pause screen over an app that has reached its limit
• Notifications warn you before a limit, during a focus session, or for a reminder
• The notification counter, if you enable it, stores only the count — not the title or the text
• The camera is used only to scan a pairing QR code. Decoding runs on the device

SYNC, OPTIONAL
Sync is off until you turn it on. When it is on, the phone encrypts the backup with a key that stays on your devices (AES-GCM) and sends only ciphertext to the server you choose.

You can run the open-source sync server yourself, for free. Or you can use Unscroll Cloud, the hosted server, at €2.99/month or €24/year, with a 14-day trial and no card required to start. After a trial or a subscription ends, the encrypted server copy is kept for 30 days and then deleted.

Unscroll Cloud payments go through Stripe. Stripe receives an anonymous account id and the details you enter in Checkout. Usage data never goes to Stripe.
