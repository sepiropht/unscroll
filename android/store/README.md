# Play Store pack for Unscroll Android

This folder is ready to paste into Google Play Console for `com.elimbi.unscroll` version 1.0.2 (versionCode 3).

- `listing-en.md` / `listing-fr.md` — title, short description, full description
- `play-forms.md` — Data safety, content rating, ads, audience, and permission justifications
- `play-checklist.md` — what to do in the console, including the 12-tester / 14-day closed-test rule for personal accounts
- `graphics/` — 512×512 icon (from the app icon), 1024×500 feature graphic, and six 1080×2400 phone screenshots captured from the Android app on a headless emulator (English UI, fictional example data only; raw captures, no device frames)

The screenshots are raw 1080×2400 captures of the English UI on a headless Android 14 emulator, seeded with fictional example data only (taken from the 1.0.1 debug build before the applicationId change; the UI is unchanged in 1.0.2). The developer’s phone was not used. Icon and feature graphic are unchanged.

The upload keystore is not in this folder and must not be committed.
