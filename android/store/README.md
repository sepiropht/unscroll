# Play Store pack for Unscroll Android

This folder is ready to paste into Google Play Console for `app.unscroll` version 1.0.1 (versionCode 2).

- `listing-en.md` / `listing-fr.md` — title, short description, full description
- `play-forms.md` — Data safety, content rating, ads, audience, and permission justifications
- `play-checklist.md` — what to do in the console, including the 12-tester / 14-day closed-test rule for personal accounts
- `graphics/` — 512×512 icon (from the app icon), 1024×500 feature graphic, and six 1080×2400 phone screenshots captured from Android app 1.0.1 (`app.unscroll`) on a headless emulator (English UI, fictional example data only; raw captures, no device frames)

The screenshots are raw 1080×2400 captures of the English 1.0.1 debug build on a headless Android 14 emulator, seeded with fictional example data only. The developer’s phone was not used. Icon and feature graphic are unchanged.

The upload keystore is not in this folder and must not be committed.
